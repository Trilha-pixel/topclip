# Créditos das peças

Cada peça foi **reescrita do zero em Python/PIL** a partir da ideia de um componente web
de licença livre. Nenhuma linha de código veio das bibliotecas abaixo; o crédito fica aqui
porque a ideia (o que a peça faz e como entra) é delas.

| Peça | Ideia de | Licença |
| --- | --- | --- |
| `contador` | Number Ticker — Magic UI (magicui.design) | MIT |
| `marca_texto` | rough-notation (Preet Shihn) e Highlighter — Magic UI | MIT |
| `troca_palavra` | Word Rotate — Magic UI | MIT |
| `desfoque` | Text Effect — Motion Primitives (ibelick) e Blur Fade — Magic UI | MIT |
| `cascata` | Animated List — Magic UI | MIT |
| `antes_depois` | Image Comparison — Motion Primitives | MIT |
| `cartao` | — (cartão de conteúdo genérico) | — |
| `brilho` | Animated Shiny Text — Magic UI | MIT |
| `moldura` | — (filete duplo com leques Art Deco, desenhado para o Luxo) | — |
| `lottie` | renderiza com thorvg-python (wrapper LGPL, ThorVG MIT), instalado como dependência | LGPL / MIT |

**Fora do repositório por licença:** React Bits (MIT + Commons Clause, que proíbe até a
"ported version"), Animate UI (MIT + Commons Clause), Aceternity UI e Skiper UI
(proprietárias). Servem só como referência visual, nunca como código ou port.
